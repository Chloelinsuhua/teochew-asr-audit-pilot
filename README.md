# teochew-asr-audit · pilot

A pre-enrolment pilot study for a doctoral project on **equity in automatic speech
recognition for low-resource Sinitic varieties**.

The study asks one narrow question that can be answered without training any model:

> When a single speaker says the same thing in two varieties, how much of the difference
> in measured accuracy is attributable to the variety — and how much to the convention
> used to write the reference?

---

## Design

| | |
|---|---|
| Speaker | 1 native speaker of Teochew (also a Mandarin speaker) |
| Material | 10 propositions, each recorded twice: once in Teochew, once in Mandarin |
| Total | 20 utterances (2.3–47.9 s, ~3 min), quiet indoor setting, single device |
| System | Whisper-large-v3, zero-shot, `language="zh"` (the only Sinitic token available) |
| Scoring | character-level edit distance, punctuation and whitespace removed; computed with and without traditional–simplified folding |

The paired design is the point: **propositional content, speaker, channel, device and
decoder are held constant**, so the language variety is the only manipulated variable.

## Results

| Condition | CER (as scored) | CER (trad./simp. folded) | Utterances correct |
|---|---|---|---|
| Mandarin (n = 10) | 14.00% | **3.33%** | 9 / 10 |
| Teochew (n = 10) | **95.17%** | 95.17% | 0 / 10 |

Two findings.

**1. Exclusion, not accent bias.** The gap is not a gradient penalty inside the system's
coverage; it is categorical. Whisper offers no Teochew language token, so Teochew is
decoded as Mandarin. On the Mandarin half the same system, same speaker, same session is
near-perfect.

**2. The reference convention moves the number fourfold.** The ten Mandarin transcripts —
with the recognition output byte-identical — score 14.00% when traditional and simplified
character forms are treated as distinct and 3.33% when they are folded. Nothing about the
recognition changed; only the rule for writing the reference did. This occurs on the
model's dominant variety, where a written standard exists. For Teochew, which has no
standard written form, the equivalent decision has no principled resolution.

In addition, the Teochew transcripts are not noise but systematic Mandarin-shaped
rewrites preserving rough phonological shape (无→摩, 来→拉, 爱→艾, 底→帝, 阿姊→阿姨).
Character-level scoring partially credits this, because the two varieties share an
orthography: `伊无来 → 伊摩拉` is credited one character in three while conveying none of
the proposition. Character overlap and communicative success come apart.

## Limits (stated deliberately)

One speaker, twenty utterances, one system, one decoding configuration. This is evidence
that the pipeline can be specified, executed and interpreted — **not** evidence about how
error is distributed across a speaker population. No distributional claim is made, and the
Accent Equity Score proposed in the proposal exists precisely because a sample of this
size cannot support one.

## Reproducing

```bash
pip install -r requirements.txt        # torch, faster-whisper, datasets, soundfile, jiwer, pandas

python 07_convert_audio.py             # m4a -> 16 kHz mono wav
python 06_record_own.py                # transcripts.tsv -> data/metadata.csv
python 02_transcribe.py --model large-v3 --tag A_whisper_large --limit 0
python 03_score.py
```

`07_convert_audio.py` uses [PyAV](https://pypi.org/project/av/) rather than a system
`ffmpeg`, so no external binary is required.

## Files

| Path | Contents |
|---|---|
| `data/my_data/transcripts.tsv` | reference transcriptions; tab-separated |
| `data/metadata.csv` | generated by `06_record_own.py`, consumed by `02_transcribe.py` |
| `results/pilot_final.csv` | per-utterance CER under both scoring conventions |
| `02_transcribe.py` | decoding loop (resumable; flushes every 10 items) |
| `03_score.py` | normalisation and dual-reference CER |
| `06_record_own.py` | builds `metadata.csv` from the transcript table |
| `07_convert_audio.py` | converts recordings to 16 kHz mono WAV via PyAV |

All text files are UTF-8. No audio is included in this repository; the
recordings remain with the author.

### Schema of `results/pilot_final.csv`

| Column | Meaning |
|---|---|
| `condition` | `teochew` or `mandarin` |
| `item` | utterance identifier within the condition |
| `reference` | reference transcription (Teochew orthography, or the Mandarin utterance in the `mandarin` condition) |
| `hypothesis` | system output, as returned by Whisper |
| `reference_mandarin` | the same proposition in standard written Mandarin |
| `cer_raw` | CER against `reference` exactly as written |
| `cer_folded` | CER against `reference` after folding traditional and simplified character variants in both strings |
| `exact_match` | 1 if `hypothesis` equals `reference` after folding, else 0 |

`cer_raw` and `cer_folded` differ only in the treatment of character variants.
On the Mandarin half they are 14.00% and 3.33% respectively, from an identical
set of hypotheses.

## Note on Teochew-Wild

The published Teochew-Wild corpus (Pan et al., 2025, arXiv:2505.05056) is gated on
HuggingFace and could not be accessed for this pilot; the data here were recorded by the
author. Published figures from that paper are cited in the proposal but are not reproduced
here.
